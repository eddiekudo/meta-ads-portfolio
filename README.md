# Aditya Rawat — Meta Ads & Performance Marketing Portfolio

An interactive, high-performance portfolio website built for showcasing paid social campaigns, ad creative testing, and full-funnel analytics for Meta Ads (Facebook & Instagram).

Styled with authentic **Notion Design System** tokens in both **Light and Dark mode**.

---

## ✨ Features

- **Continuous Sliding Creative Carousel**: 60fps hardware-accelerated infinite glide showcasing real campaign creatives categorized across TOFU, MOFU, and BOFU funnel stages. Supports pause-on-hover, manual drag (`drag="x"`), and quick navigation arrows.
- **Interactive Ad Inspector**: Click any ad creative to open a deep-dive inspection modal displaying target demographics, hook rates, CTR, CPC, placement breakdowns, and creative rationale.
- **Full-Funnel Interactive Analytics Hub (Recharts)**:
  - **Profitable Scaling (Dual-Axis Combo Chart)**: Daily ad spend (bars) vs. attributed revenue and ROAS (line) with interactive toggle.
  - **CPA Compression & Milestones (Annotated Line Graph)**: Cost-per-order compression over the 14-day sprint annotated with strategic creative interventions.
  - **Customer Journey & Funnel Drop-off (Step Bar Chart)**: Clear step conversions from cold impressions down to 77 paid purchases with a 70% checkout-to-purchase benchmark.
  - **Budget & Placement Distribution (Donut Chart)**: Visualizing the 55/25/20 funnel budget split and Reels/Feed placement allocation.
  - **Creative Testing & Takeover (Grouped Bar Chart)**: A/B creative test hypothesis comparisons and before/after account takeover results.
- **Notion Dark & Light Theme**: Seamless toggle persisting user preference and matching system settings (`prefers-color-scheme`).
- **Currency Switcher**: Toggle metrics dynamically between INR (₹) and USD ($).

## 🛠 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with Notion Design System tokens
- **Animations**: [Motion / Framer Motion](https://motion.dev/)
- **Data Visualization**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/eddiekudo/meta-ads-portfolio.git
cd meta-ads-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
The output will be generated in the `dist/` directory.
